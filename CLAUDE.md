# Mech Workshop: notes for Claude

- **All 3D models and environments are made in Blender**, generated by Python
  scripts in `tools/blender/` (run headless: `blender -b --factory-startup --python ...`).
  Never hand-author meshes in Godot or pull in third-party models. Edit the build
  script, rebuild, and commit the script, `.glb`, `.blend`, and preview PNGs together.
- Build one asset/environment at a time; look at the preview render in
  `docs/previews/` before moving on.
- Blender needs `python3-numpy` for the glTF exporter (`apt-get install blender python3-numpy`).
- Part stats live in the Blender part builders (`mech_parts.py` -> root extras) and
  are exported to `data/parts.json`; don't edit that JSON by hand.
- Engine: Godot 4.3+, GDScript, 4-space indentation.
- Naming contract between Blender and game code (see `tools/blender/common.py`):
  `socket_*`, `joint_*` (gait IK drives `joint_hip/knee/ankle_*`), `armor_*`, `weak_point*`, `*_collider`, `cockpit_camera`,
  environment markers `spawn_A/B`, `gate_A/B_start`, `mech_spawn`, `salvage_spot_*`, `sell_point`,
  `exit_to_workshop`, and extras `{"collision": "box"|"convex"|"mesh"}`,
  `{"destructible": true, "hp": n, "explosive": bool}`, lights `{godot_energy, godot_range}`,
  arena doors `{gate, side, slide}` (slide along local X),
  cockpit markers `screen_status/radar/weapons` (Godot +Z faces pilot), `glass_crack_1..3`,
  `stick_pivot_L/R` (joysticks; pilot hands + forearms parented to them),
  `arm_shoulder_L/R` (upper arm along local +Y; game aims it at) `arm_elbow_L/R`,
  `holo_hud` (UV'd plane) + `holo_frame` (Godot +X right, +Y up, +Z to pilot; extras w/h in m).
- Godot 4.3 drops glTF node extras: every Blender export also writes `<file>.glb.extras.json`, and the game
  re-attaches it (`LevelUtils.apply_extras` / `instance_scene`). Always load models through those helpers.
- Smoke test (run after changes): `godot --headless --path . res://tests/smoke_test.tscn` -> `SMOKE TEST: PASSED`.
- Playtest builds: the user only wants the **Windows** zip. Export just the "Windows" preset
  (`godot --headless --path . --export-release "Windows" build/windows/MechWorkshop.exe`), zip it with
  `docs/PLAYTEST.txt` as `build/MechWorkshop-playtest-<version>-windows.zip`, and send only that file.
- Quick draft renders: `PREVIEW_SCALE=0.4 blender -b ... --python tools/blender/build_X.py`.
