# Mech Workshop: notes for Claude

- **All 3D models and environments are made in Blender**, generated by Python
  scripts in `tools/blender/` (run headless: `blender -b --factory-startup --python ...`).
  Never hand-author meshes in Godot or pull in third-party models. Edit the build
  script, rebuild, and commit the script, `.glb`, `.blend`, and preview PNGs together.
- Build one asset/environment at a time; look at the preview render in
  `docs/previews/` before moving on.
- Blender needs `python3-numpy` for the glTF exporter (`apt-get install blender python3-numpy`).
- Part stats live in the Blender part builders (`mech_parts.py` -> root extras) and
  are exported to `data/parts.json`; don't edit that JSON by hand.
- Engine: Godot 4.3+, GDScript, 4-space indentation.
- Naming contract between Blender and game code (see `tools/blender/common.py`):
  `socket_*`, `joint_*`, `armor_*`, `weak_point*`, `*_collider`, `cockpit_camera`,
  environment markers `spawn_A/B`, `mech_spawn`, `salvage_spot_*`, `sell_point`,
  `exit_to_workshop`, and extras `{"collision": "box"|"convex"|"mesh"}`,
  `{"destructible": true, "hp": n, "explosive": bool}`, lights `{godot_energy, godot_range}`.
- Quick draft renders: `PREVIEW_SCALE=0.4 blender -b ... --python tools/blender/build_X.py`.
